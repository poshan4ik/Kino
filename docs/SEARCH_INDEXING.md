# Поиск сайта в Google и Яндексе

Это учебная демонстрация. Настоящие билеты не продаются; расписание и отзывы тестовые.
Сайт уже размещён на Render: https://kino-aurora.onrender.com/ . Повторный хостинг не требуется.

## Что настроено в коде

- Главная и страницы фильмов доступны без входа, отдаются сервером как HTML.
- Canonical и og:url указывают основной адрес без поисковых параметров.
- /movie/<id>/ и /film/<id>/ имеют один canonical — /film/<id>/.
- sitemap.xml включает активные и ожидаемые фильмы, исключает архивные.
- robots.txt разрешает публичные страницы, закрывает служебные разделы.
- Страницы авторизации и личные разделы имеют noindex в HTML.
- SITE_URL фиксирует основной адрес. По умолчанию используется RENDER_EXTERNAL_URL.
- Метатеги подтверждения доступны через переменные окружения без изменения шаблонов.

## Google Search Console

1. Откройте https://search.google.com/search-console/welcome под своим Google-аккаунтом.
2. Выберите **Ресурс с префиксом в URL**, а не «Доменный ресурс»: DNS домена onrender.com принадлежит Render.
3. Введите ровно https://kino-aurora.onrender.com/ .
4. Выберите подтверждение HTML-тегом. Скопируйте только значение content из google-site-verification.
5. В Render → сервис kino-aurora → Environment добавьте GOOGLE_SITE_VERIFICATION с этим значением.
6. Сохраните изменения с повторным развёртыванием. Проверьте метатег в HTML главной, затем нажмите подтверждение в Google.
7. В «Файлы Sitemap» отправьте https://kino-aurora.onrender.com/sitemap.xml .
8. В «Проверка URL» проверьте главную и при необходимости запросите индексирование.

## Яндекс Вебмастер

1. Откройте https://webmaster.yandex.ru/ и добавьте https://kino-aurora.onrender.com/ .
2. Выберите метатег yandex-verification, скопируйте значение content.
3. В Render Environment добавьте YANDEX_VERIFICATION, сохраните с развёртыванием и подтвердите права в Вебмастере.
4. В «Индексирование → Файлы Sitemap» добавьте https://kino-aurora.onrender.com/sitemap.xml .
5. В «Переобход страниц» отправьте главную и страницы фильмов. Проверяйте диагностику и индексирование.

Не удаляйте коды подтверждения после успешной проверки.
Индексация и позиции в выдаче не гарантируются, точный срок заранее неизвестен.
Оператор site: — вспомогательная проверка; надёжнее смотреть данные кабинетов владельца.

## Обновление на Render

После коммита выполните Manual Deploy → Deploy latest commit, если Auto-Deploy выключен.
Проверьте в Environment:

- SITE_URL=https://kino-aurora.onrender.com
- DEMO_MODE=True только для учебной демонстрации
- GOOGLE_SITE_VERIFICATION и YANDEX_VERIFICATION — собственные значения из кабинетов

В демо-режиме первое открытие главной периодически дополняет расписание ближайших десяти дней
для демонстрационных активных фильмов. Старые сеансы, брони, пользователи и оплаты не удаляются.
В реальном кинотеатре задайте DEMO_MODE=False: даты и цены должны вводиться сотрудниками.
Смена этих настроек не делает демонстрационные платежи настоящими.

## Проверки

```bash
python manage.py check
python manage.py test cinema.tests --noinput
```

Проверьте ответы 200 для главной, /robots.txt, /sitemap.xml и страниц фильмов.
После изменения хостинга не переносите базу на новый сервис без резервного копирования.
Не включайте новые платные ресурсы Render только ради индексации: сначала проверьте фактическую доступность.
